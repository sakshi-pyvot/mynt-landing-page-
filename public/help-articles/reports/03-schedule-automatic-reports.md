# How to Schedule Automatic Reports

*Reports · Read time: 3 minutes · Article only · Last updated 25 August 2026*

The same builder can deliver a report on a recurring basis instead of once. Set it up in the same place.

---

## One-Time or Schedule

![The delivery type control offering One-Time or Schedule Report](assets/schedule-automatic-reports/step-01-delivery-type.png)
*Switch <strong>Delivery Type</strong> to <strong>Schedule Report</strong> to make it recurring*

1. Fill in the report as you would for a one-off: type, platform, outlets, period.
2. Choose the **Delivery Channel**.
3. Set **Delivery Type** to **Schedule Report**.
4. Set how often it should run.
5. Save the schedule.

## Tokens are spent per run

A schedule spends its token cost *every time it runs*, not once when you create it. A daily WhatsApp report costs roughly thirty times what a monthly one does. Check the cost summary before saving, and keep an eye on your balance &mdash; see [checking your balance](../tokens/03-how-to-check-token-usage-balance-get-more.md).

> **Tip:** Choose **Download** or **Email** for anything that runs daily. WhatsApp is the most expensive channel per run.

## Choosing a sensible frequency

| | |
|---|---|
| **Daily** | Operational review. Use the cheapest channel. |
| **Weekly** | Matches most payout cycles, so the data is usually complete. |
| **Monthly** | Accounting and reconciliation. |

Weekly generally lines up best with when platforms actually settle &mdash; see [how often Mynt syncs](../email-integration/05-how-often-sync.md).
