How to Download Raw Data

Reports · Read time: 3 minutes · Includes a short video · Last updated 18 November 2026

Take the underlying order, ads and accounting data into your own spreadsheet.

Choosing last month’s order and accounting data for two outlets

When to use it

Reports summarise. Download Raw Data, at the bottom of the Reports page, gives you the underlying platform data in a spreadsheet, to work with yourself or hand to your accountant.

Download it

  1. Choose the Platform.
  2. Choose the Duration: Previous Day, Previous Week, Previous Month, Previous Quarter, Current Month, or a Custom Date Range.
  3. Choose the Raw Data Types: Order Data, Ads Data and/or Accounting Data.
  4. Choose the Outlets.
  5. Pick the File Format and Data Arrangement, check the estimate, and click Generate and Download Raw Data.
Order DataOne row per order, with the columns from that platform’s own statement, a sheet per platform.
Ads DataAd spend, a sheet per platform.
Accounting DataThe Accounting Summary’s workings as Excel: one row per outlet with GSTIN, sales, GST, commission, ads, TCS, TDS and net payout. Net sales, net payout and the totals are live formulas, and a Column Formulas sheet explains each column.

Format and arrangement

ExcelOne .xlsx file with a sheet for each type and platform, and a Summary sheet of the choices you made.
CSVA .zip with one .csv per sheet.
Combined FileEverything in one file.
Separate File per Res-IDA .zip with one file for each outlet on each platform.

Cost and limits

The summary shows the date range, an estimated file size, the estimated token cost and your balance. The cost is per file, so the figure shown is a starting point: From N tokens. A CSV or a separate file per Res-ID makes more files and costs more. Your balance is checked against the real cost before anything is charged.

  • A custom date range can cover up to 90 days, and can’t start more than 90 days ago. For older data, use Previous Month or Previous Quarter.
  • If the download fails after the export was made, try again with the same choices: it downloads again without a second charge.
  • Every export is listed in Report History with the source Raw data.
