# How to Download Raw Data

*Reports · Read time: 3 minutes · Includes a short video · Last updated 18 November 2026*

Take the underlying order, ads and accounting data into your own spreadsheet.

## When to use it

Reports summarise. <b>Download Raw Data</b>, at the bottom of the Reports page, gives you the underlying platform data in a spreadsheet, to work with yourself or hand to your accountant.

## Download it

![The Download Raw Data card with Platform, Duration, Raw Data Types and Outlets](assets/how-to-download-raw-data/step-01-form.png?v=20261118)
*Four choices, then the format*

1. Choose the <b>Platform</b>.
2. Choose the <b>Duration</b>: Previous Day, Previous Week, Previous Month, Previous Quarter, Current Month, or a Custom Date Range.
3. Choose the <b>Raw Data Types</b>: <b>Order Data</b>, <b>Ads Data</b> and/or <b>Accounting Data</b>.
4. Choose the <b>Outlets</b>.
5. Pick the <b>File Format</b> and <b>Data Arrangement</b>, check the estimate, and click <b>Generate and Download Raw Data</b>.

| | |
|---|---|
| **Order Data** | One row per order, with the columns from that platform’s own statement, a sheet per platform. |
| **Ads Data** | Ad spend, a sheet per platform. |
| **Accounting Data** | The Accounting Summary’s workings as Excel: one row per outlet with GSTIN, sales, GST, commission, ads, TCS, TDS and net payout. Net sales, net payout and the totals are live formulas, and a Column Formulas sheet explains each column. |

## Format and arrangement

| | |
|---|---|
| **Excel** | One .xlsx file with a sheet for each type and platform, and a Summary sheet of the choices you made. |
| **CSV** | A .zip with one .csv per sheet. |
| **Combined File** | Everything in one file. |
| **Separate File per Res-ID** | A .zip with one file for each outlet on each platform. |

## Cost and limits

The summary shows the date range, an estimated file size, the estimated token cost and your balance. The cost is per file, so the figure shown is a starting point: <b>From N tokens</b>. A CSV or a separate file per Res-ID makes more files and costs more. Your balance is checked against the real cost before anything is charged.

- A custom date range can cover up to 90 days, and can’t start more than 90 days ago. For older data, use Previous Month or Previous Quarter.
- If the download fails after the export was made, try again with the same choices: it downloads again without a second charge.
- Every export is listed in <b>Report History</b> with the source <b>Raw data</b>.
