# How to Generate and Download a Report

*Reports · Read time: 3 minutes · Includes a short video · Last updated 22 October 2026*

Fill in four fields, check the token cost, and generate. The cost is always shown before you commit.

---

## Watch it done

**Video:** [Generating a report, sending it by email and WhatsApp, then scheduling it weekly](assets/how-to-generate-and-download-report/demo.mp4?v=20261022)

![Video preview](assets/how-to-generate-and-download-report/demo-poster.jpg?v=20261022)

## Step 1 — define the report

1. Choose a **Report Type**.
2. Choose the **Platform** &mdash; one or more, or **All Platforms**.
3. Choose the **Outlets** to include.
4. Choose the **Report Period**.

## Step 2 — choose how it reaches you

![The delivery channel options with their token costs](assets/how-to-generate-and-download-report/step-01-delivery-channel.png?v=20261022)
*Each channel has its own token cost, shown on the option itself*

| | |
|---|---|
| **Download** | The file comes straight back to you. Priced per file. |
| **Email** | Sent to the addresses you type under **Email Recipients** (at least one), plus any **CC Recipients (optional)**. Priced per recipient. |
| **WhatsApp** | Sent to the numbers you type under **WhatsApp Recipients** (at least one). Priced per recipient. |

You can pick more than one channel. Each option shows its price, for example "N tokens/participant" for Email and WhatsApp. Prices are set by Mynt and can change, so go by what the option shows.

## Step 3 — check the cost

![The cost summary showing tokens per run and the current balance](assets/how-to-generate-and-download-report/step-02-cost-summary.png?v=20261022)
*Tokens per run against your current balance &mdash; visible before you generate*

If the balance is too low, the summary shows **Insufficient balance** and you cannot generate. Top up first &mdash; see [checking your balance and getting more](../tokens/03-how-to-check-token-usage-balance-get-more.md).

## Step 4 — generate

Press the button at the bottom. It reads **Generate Report** until you pick a channel, then follows the channel you chose: **Generate and Download**, **Generate and Email**, or **Generate and Send** (WhatsApp, or several channels at once). With Download the file comes back to you; with Email or WhatsApp it goes to the recipients you entered. If one is missing, Mynt asks you to add it, for example "Add an email recipient to continue." **Reset** clears the form and starts again.

> **Tip:** Generate one small report first to confirm the type and period are what you expect. Tokens are spent per run, so a wrong setting costs a second run.

## If a report does not arrive

1. Check **Help & Support → System Status** for any service marked **Delayed** or **Down**.
2. For email delivery, ask each recipient to check their spam folder.
3. Confirm the token balance was sufficient at the time.
4. Still missing? [Raise a ticket](../data-issues/06-how-to-raise-data-issue-support-ticket.md) with issue type **Report**.
